## 🧪 Verification Commands

Test any feed URL:
```bash
# Quick validation
curl -s "https://openai.com/blog/rss.xml" | head -20

# Check feed type
curl -sI "https://openai.com/blog/rss.xml" | grep -i content-type

# Count items
curl -s "https://openai.com/blog/rss.xml" | grep -c "<item>"
```

### Feed Health Checks
- ✅ **RSS 2.0**: Standard `<item>` elements
- ✅ **Atom 1.0**: `<entry>` elements with `<link rel="alternate">`
- ⚠️ **Redirects**: Some feeds redirect (follow with `-L`)
- ⚠️ **Rate limits**: Add `User-Agent` header for production

---

## 📝 Implementation Recommendations

1. **Deduplication**: Use GUID/link hashing across all feeds
2. **Rate limiting**: Respect `ttl`/`updatePeriod` in feed headers
3. **Content filtering**: For high-volume feeds (arXiv, Dev.to), filter by:
   - Keywords: `llm`, `transformer`, `generative`, `agent`, `rag`, `fine-tun`
   - Authors: Known researchers/labs
   - Categories: ML/AI tags
4. **Language detection**: Tag Portuguese/English content for AI generation
5. **Source weighting**: Prioritize primary sources (labs) over aggregators
